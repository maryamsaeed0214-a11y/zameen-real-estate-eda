# 🏠 Zameen.com Real Estate Exploratory Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a Zameen.com real estate dataset. The objective is to analyze property prices, compare cities and property types, identify market trends, and generate insights that can support real estate decision-making.

---

## 🎯 Objectives

- Understand the structure of the dataset
- Handle missing and duplicate values
- Clean and preprocess the data
- Perform feature engineering
- Explore property price trends
- Compare cities and property types
- Generate meaningful business insights

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## 📂 Project Workflow

1. Data Understanding
2. Missing Value Treatment
3. Duplicate Value Handling
4. Data Cleaning
5. Feature Engineering
6. Exploratory Data Analysis
7. Data Visualization
8. Insights
9. Conclusion

---

## 📊 Key Analysis

- Property price distribution
- City-wise price comparison
- Property type analysis
- Relationship between area and price
- Market trends and insights
